## 🆘 Troubleshooting Guide

### Issue: Page shows "404 Not Found"
- Check: Are routes in web.php?
- Read: RECOVERY_DISTRIBUTION_SETUP.md → Routes section

### Issue: Database errors
- Check: Has migration run?
- Read: RECOVERY_QUICK_START.md → Step 1

### Issue: Summary shows 0 everywhere
- Check: Is there recovery data?
- Read: TESTING_GUIDE.md → Test 2

### Issue: Can't delete recovery
- Check: Does it have distributions?
- Read: RECOVERY_SYSTEM_URDU_GUIDE.md → Delete section

### Issue: Form validation error
- Check: Exceeding pending amount?
- Read: RECOVERY_DISTRIBUTION_FEATURE.md → Validation

### Issue: Need to understand the logic
- Read: RECOVERY_SYSTEM_URDU_GUIDE.md (best explanation)
- Then: RECOVERY_SYSTEM_VISUAL_GUIDE.md (visual)
